# Celer Network

> Celer Network is a blockchain interoperability protocol enabling seamless cross-chain experiences. Its cBridge cross-chain asset bridge supports 40+ blockchains with $14B+ in transfer volume, and Celer IM (Inter-chain Messaging) lets developers build inter-chain-native dApps with coherent logic and shared state. The cBridge gateway exposes a public gRPC-Web / REST API for chain/token discovery, fee estimation, transfer status, and liquidity withdrawal.

## Operations

- GetTransferConfigs — GET /v1/getTransferConfigs — supported chains and tokens
- GetTokenInfo — GET /v1/getTokenInfo — chain and token info
- EstimateAmt — GET /v1/estimateAmt — estimate transfer fee and received amount
- GetTransferStatus — POST /v1/getTransferStatus — transfer status by id
- WithdrawLiquidity — POST /v1/withdrawLiquidity — remove liquidity / refund (signed)
- EstimateWithdrawAmt — POST /v1/estimateWithdrawAmt — estimate withdrawal
- TransferHistory — GET /v1/transferHistory — user transfer history (cursor paginated)
